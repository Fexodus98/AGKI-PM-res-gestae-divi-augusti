# User Stories — Developer / Technically Interested

- As a developer, I want to see the repository structure and build instructions so I can run or extend the site locally.
- As a developer, I want the TEI → HTML/JSON pipeline documented (scripts/XSLT, inputs/outputs) so I can modify or automate it.
- As a developer, I want clearly versioned assets (TEI, registers, timeline) with checksums so I can verify integrity when mirroring.
- As a developer, I want small, dependency-light front-end code so I can integrate the edition into other static sites.
- As a developer, I want example API-less fetch patterns (raw URLs) so I can programmatically pull updates without extra auth.
