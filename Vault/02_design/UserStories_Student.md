# User Stories — Student

- As a student, I want a clean reading mode with optional annotation highlights so I can focus on the text and reveal context when needed.
- As a student, I want short tooltips for unfamiliar names/places and links to a register so I can learn without leaving the page.
- As a student, I want a simple language toggle (single-column tabs) so I can compare translations without being overwhelmed.
- As a student, I want chapter jump links and a search box so I can quickly find themes or assignments.
- As a student, I want a glossary-like register and timeline to grasp who is involved, where events happen, and when they occur.
