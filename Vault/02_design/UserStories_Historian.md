# User Stories — Historian

- As a historian, I want parallel Latin/Greek/German display aligned by segment so I can verify wording across versions.
- As a historian, I want chapter-level navigation with stable anchors so I can cite and return to specific passages.
- As a historian, I want inline annotations (people/places/events) with hover summaries and deeper notes in a side panel so I can assess context quickly.
- As a historian, I want a timeline view linked to the annotated events so I can situate passages chronologically.
- As a historian, I want to download the canonical TEI and per-chapter TEI to review the editorial markup and reuse it in my own work.
