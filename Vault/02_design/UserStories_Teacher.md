# User Stories — Teacher

- As a teacher, I want ready-to-share chapter links and a printable view so I can assign specific passages to students.
- As a teacher, I want toggles to simplify the UI (e.g., hide advanced filters) so learners stay focused on the text.
- As a teacher, I want concise annotation summaries and glossary entries I can trust to be classroom-safe.
- As a teacher, I want timeline and map-style views to illustrate when and where events occur during lectures.
- As a teacher, I want downloadable packets (PDF/HTML) for selected chapters and languages to use offline in class.
