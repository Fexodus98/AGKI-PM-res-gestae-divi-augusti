# User Stories — DH Researcher

- As a DH researcher, I want direct download links to the full TEI and derived datasets (registers/timeline JSON) so I can run my own analyses.
- As a DH researcher, I want stable IDs and link groups exposed in the HTML so I can map segments across languages programmatically.
- As a DH researcher, I want documentation of the transformation pipeline (TEI → HTML/JSON) and prompts used for annotation so I can reproduce or adapt the workflow.
- As a DH researcher, I want inspectable annotation layers (people/places/events) with type filters and export options so I can validate and extend them.
- As a DH researcher, I want a lightweight API-less way (raw file URLs) to fetch assets so I can script downloads without authentication.
